# 有页面时才插入 UI 设计师

页面外观若交给架构师或研发人员顺手做，产品界面会落到通用皮肤上。UI 设计师放在产品之后、架构师之前，只在这次涉及页面时开工。默认遵循 impeccable 和 make-interfaces-feel-better。手机屏幕图用 imagegen-frontend-mobile，网页产品再用 frontend-design-direction。落地页才用 design-taste-frontend。固定网站风格和单平台技能不作为默认。角色文件使用 agency-agents 里 UI Designer 的完整段落：身份与记忆、使命、关键规则、交付物、工作流、交付模板、沟通方式、学习与记忆、成功标准、进阶能力。
